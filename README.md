Descripción General
Supóngase que ha sido contratado/a como desarrollador/a Front-End para diseñar el prototipo funcional de
las interfaces gráficas (GUI) de una aplicación móvil con Ionic sobre “Lugares Turísticos Colombianos”.
La aplicación debe permitir navegar entre pantallas y simular la interacción del usuario (alertas de
confirmación para agregar/eliminar lugares) sin necesidad de conectar la aplicación a un servidor web o base
de datos.
